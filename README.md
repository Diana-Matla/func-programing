# Лабораторна робота: Функціональне програмування

## Варіант 9. Розрахунок вартості оренди автомобілів

### 1. Опис завдання

Програма призначена для розрахунку вартості оренди автомобілів. Вона обробляє список бронювань, враховує тривалість оренди, знижки та вартість страхування, а також формує звіт про підтверджені оренди й загальний дохід.

Для кожного бронювання зберігаються такі дані:

* ідентифікатор бронювання;
* клас автомобіля;
* ціна оренди за день;
* кількість днів оренди;
* статус бронювання;
* загальна вартість оренди.

### 2. Реалізований функціонал

Програма містить такі функції:

* `base_price()` — обчислює базову вартість оренди;
* `duration_discount_rate()` — визначає розмір знижки залежно від тривалості оренди;
* `insurance_amount()` — визначає вартість страхування залежно від класу автомобіля;
* `is_confirmed()` — перевіряє, чи підтверджене бронювання;
* `calc_total()` — обчислює остаточну вартість оренди з урахуванням знижки та страхування;
* `with_total()` — створює новий словник бронювання з доданою загальною вартістю;
* `make_processor()` — створює налаштований обробник бронювань, який приймає функції-політики.

Знижки залежать від тривалості оренди:

* від 3 днів — 5%;
* від 7 днів — 10%;
* від 14 днів — 15%.

Вартість страхування залежить від класу автомобіля:

* Economy — 200 грн;
* Basic — 400 грн;
* Premium — 600 грн.

До звіту та розрахунку доходу включаються лише підтверджені бронювання.

### 3. Структура програми

* `core.py` — містить типи даних, чисті функції, розрахункову логіку та фабрику обробника.
* `app.py` — містить тестові дані, запускає обробку бронювань і виводить звіт.
* `test_functional.py` — містить автоматизовані тести для перевірки правильності розрахунків, відсутності мутацій, референтної прозорості та роботи функцій-політик.
* `README.md` — опис програми та інструкції із запуску.

### 4. Використані принципи функціонального програмування

У програмі реалізовано такі принципи:

* **Чисті функції:** функції розрахунків повертають результати на основі переданих аргументів.
* **Відсутність глобального стану в розрахунковому ядрі:** результати не залежать від змінних, що змінюються між викликами.
* **Відсутність мутацій:** вхідні словники та списки не змінюються під час обробки.
* **Функції вищого порядку:** `make_processor()` приймає інші функції як аргументи та повертає налаштований обробник.
* **Callable:** типізація функцій-політик за допомогою `typing.Callable` дає змогу передавати різні правила фільтрації, знижок і страхування.

### 5. Запуск програми

Для запуску програми відкрийте термінал у папці проєкту та виконайте команду:

```bash
python app.py
```

### 6. Запуск тестів

Для запуску автоматизованих тестів виконайте:

```bash
pytest -v
```

Тести перевіряють правильність основних розрахунків, повторюваність результатів, незмінність вхідних даних і можливість передавати власні функції-політики.

# Лабораторна робота №2. Функції вищого порядку, lambda, композиція

# Цілі: map / filter / reduce, функціональна композиція.

# Завдання: побудувати конвеєр перетворень над списком записів (records) без мутацій.

### Варіант 9. Працівники компанії

Структура запису: id, name, department, monthly_hours.

Конвеєр: обчислити сумарні години, застосувати коефіцієнт відділу, відфільтрувати за мінімумом, сформувати Top-N.

reduce-агрегація: count, total_hours, avg_hours.


### Обов'язкові вимоги

* Описати Record через TypedDict або еквівалентну типізовану структуру.
* Реалізувати щонайменше 4 чисті трансформації, що не змінюють вхідні записи.
* Використати filter/map або генераторні вирази для фільтрації та перетворень.
* Реалізувати compose або pipe та зібрати з її допомогою конвеєр.
* Використати lambda щонайменше у двох доречних операціях.
* Виконати сортування з двома ключами та сформувати Top-N.
* Реалізувати reduce-агрегацію з не менш ніж трьома статистичними показниками.
* Написати pytest-тести: коректність Top-N, відсутність мутацій, правильність агрегації та композиції.
* Винести I/O та CLI у main.py; чисті функції залишити у lab2.py.
* Додати README.md та забезпечити проходження black, ruff і mypy.

### Склад проєкту

lab2/lab2.py - реалізація конвеєра (map/filter/reduce, compose, pipe, juxt) + агрегації.
lab2/tests/test_lab2.py - тести для pytest.
lab2/sample_data.json - приклад вхідних даних.
lab2/main.py - простий CLI-демо запуск.
ASSIGNMENT.md - завдання та критерії оцінювання.
README.md, pyproject.toml, requirements.txt - інструкції та конфіг.
